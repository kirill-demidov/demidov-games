# Сапёр.exe

Классический Minesweeper в окне Windows 95. Рекорды пишутся в **PostgreSQL** через небольшое API.

## Запуск с таблицей рекордов

Нужен Docker. Из этой папки:

```bash
docker compose up --build
```

Игра и API: [http://localhost:8090](http://localhost:8090)

Postgres слушает `localhost:5433` (логин/пароль/база: `sapper`).

Победа уходит в `POST /api/scores`, таблица читается из `GET /api/scores`. Если API недоступен, игра продолжает работать и держит локальный кэш в браузере.

## GitHub Pages

Статика может лежать на Pages, но общая таблица живёт на API. После деплоя бэкенда пропиши адрес в `config.js`:

```js
window.SAPPER_API = "https://example.com";
```

## Как играть

- Левый клик / тап — открыть клетку
- Правый клик / долгое нажатие / кнопка «Флаг» — поставить флаг
- Двойной клик по цифре — открыть соседей, если флаги уже стоят
- F2 или смайлик — новая партия
- Первый клик всегда безопасный
